Radio Kootwijk is a long wave transmitter station located in Hooge Veluwe Park near Arnhem in Netherlands, connected from 1923 to 1966 to Radio Malabar near Bandung in East India.
The main building was part of the movie Mindhunters and TV show Arkadia which inspired me to some more elements in this layout.
